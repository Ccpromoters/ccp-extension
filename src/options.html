CCP Extension – Settings

Everything below is stored in this Chrome profile only. Each candidate's profile gets its own settings and master resume.

Candidate

Comma-separated. Used to focus the skills-gap view.

Master resumes (.docx)

Upload the candidate's final resume as a Word file. The extension edits a copy per job: it adds JD skills to the existing skills rows and changes at most a couple of bullet points. The master file itself is never changed.

AI (for resume tailoring)

Stored only in this profile. Sent only to the provider you choose, together with the resume text and the job description. Get a key at console.anthropic.com.
For proxies or OpenAI-compatible servers (e.g. http://localhost:11434/v1 for Ollama).

Tailoring rules

Tools or claims the candidate has NOT confirmed. The AI may suggest them, but they are never written into the resume unless you type them into “confirmed terms” for that job.

Job boards & tabs

0 = first account signed in to this profile (mail.google.com/mail/u/0).

Backup

Use this to set up another candidate's Chrome profile quickly, or to move to a new computer. Applications and mail are not included.
